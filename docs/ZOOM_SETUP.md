# Zoom Setup

Zoom is disabled by default.

```env
ZOOM_ENABLED=false
NEXT_PUBLIC_ENABLE_ZOOM_EMBED=false
ZOOM_CLIENT_ID=
ZOOM_CLIENT_SECRET=
ZOOM_ACCOUNT_ID=
ZOOM_MEETING_SDK_KEY=
ZOOM_MEETING_SDK_SECRET=
```

Meeting SDK signatures are generated only on the server. Host signatures are not issued to ordinary users.
